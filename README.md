# 🛡️ Clans (Advanced Clan System)

**Clans** — это мощный и современный плагин для серверов Minecraft (Spigot/Paper 1.16.5+), предоставляющий игрокам продвинутую систему кланов с GUI-интерфейсом, уровнями, квестами и общим хранилищем.

## ✨ Основные возможности

*   **🖥️ Полный GUI Интерфейс** — Управление кланом через интуитивно понятные меню.
*   **📈 Система уровней** — Прокачивайте свой клан, зарабатывая опыт, и открывайте новые возможности.
*   **🎒 Клановое хранилище** — Общий инвентарь для участников клана с системой улучшений.
*   **📜 Задания (Quests)** — Выполняйте разнообразные задачи всем кланом для получения наград.
*   **💰 Казна клана** — Общий банковский счет для экономики клана (поддержка Vault).
*   **🏠 Дом клана** — Установка и телепортация на базу клана.
*   **⚔️ PvP Настройки** — Управление PvP внутри клана.
*   **🎨 Кастомизация** — Настройка цвета названия и тега клана.
*   **📊 Топ кланов** — Соревновательная система лидеров на сервере.
*   **🧩 PlaceholderAPI** — Полная поддержка плейсхолдеров для интеграции с другими плагинами.

## 🛠️ Команды

*   `/clan create <название> <тег>` — Создать новый клан.
*   `/clan menu` — Открыть главное меню клана.
*   `/clan invite <игрок>` — Пригласить игрока.
*   `/clan accept <тег>` — Принять приглашение.
*   `/clan sethome` — Установить точку дома клана.
*   `/clan home` — Телепортироваться на дом клана.
*   `/clan chat` — Переключить клановый чат.
*   `/clanadmin` — Команды для администраторов сервера.

## 📍 Плейсхолдеры (PlaceholderAPI)

*   `%clan_name%` — Название клана.
*   `%clan_tag%` — Тег клана.
*   `%clan_level%` — Уровень клана.
*   `%clan_progress_percent%` — Процент прогресса до следующего уровня.
*   `%clan_members%` — Количество участников.
*   `%clan_bank%` — Баланс казны.
*   ... и многие другие!

## 🚀 Установка

1. Скачайте `Clans-1.4.0.jar`.
2. Поместите его в папку `plugins` вашего сервера.
3. Установите зависимости: **PlaceholderAPI** и **Vault** (опционально для экономики).
4. Перезапустите сервер.
5. [Установите новую версию](https://alfheimguide.ct.ws/plugins?plugin_id=15)
6. [Wiki-1.5.0](https://alfheimguide.ct.ws/wiki_article?slug=clans-150)
